# illustrations

Small SVG kit for the personal log. Keep everything monochrome and thin-line so it matches `style.css`.

| file | use |
|------|-----|
| `entry-stamp.svg` | corner mark on homepage entry cards |
| `log-mark.svg` | optional nameplate accent |
| `process-diagram.svg` | starter flow diagram for entry bodies |

## making more

1. Use the greys from the site: `#1d1d1f` `#6e6e73` `#9a9a9e` `#b8b8bc` `#d2d2d6` `#e4e4e6` `#f5f5f7`
2. Prefer stroke over fill; ~0.75–1.25px stroke at the SVG’s native size
3. Export / save as SVG; avoid drop shadows, glow, and bright accents
4. No embedded text if you want the asset reusable across entries — annotate in HTML instead
